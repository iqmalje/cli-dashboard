# cockpit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `cockpit`, a Claude Code mod that draws the Panel above the prompt (Fixed Rows plus Activity Sections) and replaces the YAS status line for one user.

**Architecture:** A hooks module (`hooks/register.tsx`) listens to engine events, keeps values in `$.state` atoms, and draws one `AbovePrompt` band. All logic that can be pure is pure and tested: the Dumb Meter maths, formatting, the frame layout (cell widths, separators, drop order), the task reducer, the agent-row reducer, and the row builders. `register.tsx` only moves engine data into atoms and maps the pure output to `Text` elements.

**Tech Stack:** TypeScript and JSX against the Claude Code mod API (`claude-code`, build 2.1.295). Tests use `claude-code/testing` and run with `claude plugin test`. No npm dependencies.

**Spec:** `docs/superpowers/specs/2026-10-09-cockpit-design.md`. Glossary: `CONTEXT.md`. Visual reference: the throwaway preview at `~/.claude/dev-mods/630be510-971d-4152-b0bd-8c1141a914d7/panel-preview/hooks/register.tsx`. The frame and colour code below comes from that preview.

**API reference:** `/private/tmp/claude-502/bundled-skills/2.1.295/48c60b51621432d8f811e95a6e266579/plugin-authoring/types/claude-code.d.ts`. ## Global Constraints

- Plugin name `cockpit`. Names that start with `claude-` are refused by `claude plugin validate`.
- Repo root `~/Documents/cockpit`. Loading is through `CLAUDE_CODE_PLUGIN_DIRS` in the `env` block of `~/.claude/settings.json`.
- Zero model tokens: no `$.model` calls.
- No configuration file. Constants stay in code.
- Soft Limit = min(800,000, context window).
- Dumb State cut-offs: below 25% Smart, below 50% Coasting, below 70% Foggy, below 90% Cooked, otherwise Dumb. Hues: 160, 230, 95, 55, 10.
- Pastels: OKLCH L 0.85, C 0.07. Border: OKLCH L 0.6, C 0.05, hue 280. Empty meter: OKLCH L 0.32, C 0.02, hue 280.
- Meter glyph `\u{1FB0B}`. The gradient always flows: one frame every 120 ms, phase step 0.025 per frame.
- Nerd Font md icons get two trailing spaces. The branch glyph `\u{E0A0}` gets one.
- At most 5 agent/workflow rows. Agent Rows stay until the next user prompt.
- Narrow-terminal drop order: 7d, Session Name, dirty count, Cache Countdown, then shorten the directory to its basename.
- Every Panel row is one `Text` with `wrap="truncate-end"`. A pressable row is one `Button` with `plain` and no `hotkey`.
- The validator refuses `$` passed to anything other than a top-level function declaration (or a top-level `const` bound to one).
- Tests: pure logic only, plus one smoke test of the mounted band. No rendering-detail tests.

## Spec deviations (found in the API while planning; confirm at plan review)

Verified while planning, so not deviations: the main loop writes 1-hour cache (`ephemeral_1h_input_tokens` in this session's transcript), so `CACHE_TTL_MS` is 1 hour. Live subagent tokens come from the subagent transcripts, as YAS reads them.


1. **Workflow phase is not available.** No event or API exposes workflow phases. The workflow label shows the run name only (`workflowName` from the `Workflow` tool result).
2. **Skills toggle control.** The control is a caption in the Panel's bottom border (`󰖷 4 skills ▸`). A click on the bottom border toggles the skills/plugins row. `/cockpit-skills` does the same.

## Review Focus

1. A session with no subscription: `rateLimits` is empty. The 5h and 7d cells are left out and nothing throws. Test: Task 5, `fixedRows without rate limits`.
2. Context window unknown or 0 at session start: the Soft Limit falls back to 800k and the meter shows Smart, not NaN. Test: Task 2, `softLimit falls back when the window is 0`.
3. A narrow terminal (40 columns): every optional cell is dropped in order and no line is wider than the terminal when it fits. Test: Task 3, `planDrops drops in order until it fits`, and `every drawn line is exactly W wide`.
4. A session registry file that is mid-write or malformed: the Session Name shows `…` and the Panel still draws. Test: Task 5, `sessionNameFrom skips malformed files`.
5. A directory that is not a git repository: the Branch cell is left out. Test: Task 2, `parseGit returns null on a failed run`.

// OKLCH to sRGB hex, so every hue reads equally bright (from comet)
export const oklch = (L: number, C: number, h: number) => {
  const r = (h * Math.PI) / 180
  const a = C * Math.cos(r)
  const b = C * Math.sin(r)
  const l = (L + 0.3963377774 * a + 0.2158037573 * b) ** 3
  const m = (L - 0.1055613458 * a - 0.0638541728 * b) ** 3
  const s = (L - 0.0894841775 * a - 1.291485548 * b) ** 3
  const lin = [
    4.0767416621 * l - 3.3077115913 * m + 0.2309699292 * s,
    -1.2684380046 * l + 2.6097574011 * m - 0.3413193965 * s,
    -0.0041960863 * l - 0.7034186147 * m + 1.707614701 * s,
  ]
  const hex = (x: number) => {
    const v = x <= 0.0031308 ? 12.92 * x : 1.055 * x ** (1 / 2.4) - 0.055
    return Math.round(255 * Math.min(1, Math.max(0, v))).toString(16).padStart(2, '0')
  }
  return `#${lin.map(hex).join('')}`
}

export const pastel = (h: number) => oklch(0.85, 0.07, h)

// Where cell k of n sits on the moving gradient at frame f: a triangle wave, 0..1..0.
export const flow = (k: number, n: number, f: number) => {
  const t = (((k / Math.max(1, n) - f * 0.025) % 1) + 1) % 1
  return 1 - Math.abs(2 * t - 1)
}
```

export const STATES = [

import type { Git } from '../types'

// Display width in cells: code points, so a Nerd Font glyph outside the BMP counts once.
export const width = (s: string) => [...s].length

export const fmtTokens = (n: number) =>
  n >= 1_000_000 ? `${(n / 1_000_000).toFixed(1)}M` : n >= 1000 ? `${Math.round(n / 1000)}k` : String(n)

export const fmtDuration = (ms: number) => {
  const s = Math.max(0, Math.floor(ms / 1000))
  const h = Math.floor(s / 3600)
  if (h >= 24) return `${Math.floor(h / 24)}d`
  if (h >= 1) return `${h}h${String(Math.floor((s % 3600) / 60)).padStart(2, '0')}m`
  return `${Math.floor(s / 60)}:${String(s % 60).padStart(2, '0')}`
}

export const fmtModel = (id: string) =>
  id
    .replace(/^claude-/, '')
    .replace(/\[.*\]$/, '')
    .replace(/-(\d+)-(\d+)(-.*)?$/, ' $1.$2')
    .replace(/-(\d+)$/, ' $1')

export const shortenHome = (path: string, home: string) =>
  path === home ? '~' : home !== '' && path.startsWith(`${home}/`) ? `~${path.slice(home.length)}` : path

export const basename = (path: string) => path.split('/').filter(Boolean).pop() ?? path

// `git status --porcelain=v1 --branch`: the first line names the branch, each other line is one changed file.
export const parseGit = (exitCode: number, stdout: string): Git | null => {
  if (exitCode !== 0) return null
  const [head = '', ...files] = stdout.split('\n').filter(l => l !== '')
  const name = head.replace(/^## /, '').replace(/^No commits yet on /, '')
  const branch = name.startsWith('HEAD (') ? 'HEAD' : (name.split('...')[0] ?? name)
  return { branch, dirty: files.length }
}

// The main loop writes 1-hour cache (checked in this user's transcripts on 2026-10-09). Subagents write 5-minute cache, but this tracks the main loop only.
export const CACHE_TTL_MS = 60 * 60 * 1000

export const cacheLeft = (lastResponseAt: number | null, now: number) =>
  lastResponseAt === null ? null : Math.max(0, lastResponseAt + CACHE_TTL_MS - now)
```

```ts
import { flow, oklch, pastel } from './color'
import { width } from './format'

export type Part = {
  text: string
  color?: string
  dim?: boolean
  bold?: boolean
  // share of the cell's slack; the part is drawn as `text` repeated to that length
  grow?: number
  // a gradient across a grow part, flowing with the frame
  hues?: readonly [number, number]
}
export type Cell = { parts: readonly Part[] }
export type Section = { rows: readonly (readonly Cell[])[]; flex: number; press?: string }
export type Seg = { text: string; color?: string; dim?: boolean; bold?: boolean }
export type Line = { segs: readonly Seg[]; press?: string }
export type Drop = 'sevenDay' | 'sessionName' | 'dirty' | 'cache' | 'dirBase'

export const DROP_ORDER: readonly Drop[] = ['sevenDay', 'sessionName', 'dirty', 'cache', 'dirBase']
export const BORDER = oklch(0.6, 0.05, 280)

export const cellWidth = (c: Cell) => c.parts.reduce((n, p) => n + (p.grow === undefined ? width(p.text) : 0), 0) + 2

export const rowWidth = (cells: readonly Cell[]) => cells.reduce((n, c) => n + cellWidth(c), 0) + cells.length + 1

export const planDrops = (need: (drops: ReadonlySet<Drop>) => number, avail: number) => {
  const drops = new Set<Drop>()
  for (const d of DROP_ORDER) {
    if (need(drops) <= avail) break
    drops.add(d)
  }
  return drops
}

// Column widths for a section: the widest row per column; the slack goes to the flex column.
const fit = (s: Section, W: number) => {
  const n = s.rows[0]?.length ?? 0
  const w = Array.from({ length: n }, (_, c) => Math.max(...s.rows.map(r => (r[c] ? cellWidth(r[c]) : 2))))
  const slack = W - 2 - (n - 1) - w.reduce((a, b) => a + b, 0)
  if (slack > 0 && w[s.flex] !== undefined) w[s.flex] += slack
  return w
}

const joints = (w: readonly number[]) => {
  const set = new Set<number>()
  let x = 0
  for (const cw of w.slice(0, -1)) {
    x += cw
    set.add(x)
    x += 1
  }
  return set
}

const rule = (l: string, r: string, up: ReadonlySet<number>, down: ReadonlySet<number>, W: number) => {
  let s = l
  for (let x = 0; x < W - 2; x++) s += up.has(x) && down.has(x) ? '┼' : up.has(x) ? '┴' : down.has(x) ? '┬' : '─'
  return s + r
}

const cellSegs = (c: Cell, w: number, f: number): Seg[] => {
  const slack = Math.max(0, w - cellWidth(c))
  const weight = c.parts.reduce((n, p) => n + (p.grow ?? 0), 0)
  const growers = c.parts.filter(p => p.grow !== undefined)
  let left = slack
  const segs: Seg[] = [{ text: ' ' }]
  for (const p of c.parts) {
    if (p.grow === undefined) {
      segs.push({ text: p.text, color: p.color, dim: p.dim, bold: p.bold })
      continue
    }
    const n = weight === 0 ? 0 : p === growers[growers.length - 1] ? left : Math.round((slack * p.grow) / weight)
    left -= n
    if (!p.hues) {
      segs.push({ text: p.text.repeat(n), color: p.color, dim: p.dim })
      continue
    }
    const [a, b] = p.hues
    for (let k = 0; k < n; k++) segs.push({ text: p.text, color: pastel(a + (b - a) * flow(k, n, f)) })
  }
  segs.push({ text: ' '.repeat(weight === 0 ? slack + 1 : 1) })
  return segs
}

export const draw = (sections: readonly Section[], W: number, f: number, caption?: { text: string; press: string }) => {
  const lines: Line[] = []
  const none = new Set<number>()
  let up: ReadonlySet<number> = none
  sections.forEach((s, i) => {
    const w = fit(s, W)
    const down = joints(w)
    lines.push({ segs: [{ text: rule(i === 0 ? '╭' : '├', i === 0 ? '╮' : '┤', up, down, W), color: BORDER }] })
    for (const row of s.rows) {
      const segs: Seg[] = [{ text: '│', color: BORDER }]
      row.forEach((c, k) => segs.push(...cellSegs(c, w[k] ?? cellWidth(c), f), { text: '│', color: BORDER }))
      lines.push({ segs, press: s.press })
    }
    up = down
  })
  const bottom = rule('╰', '╯', up, none, W)
  if (!caption) {
    lines.push({ segs: [{ text: bottom, color: BORDER }] })
    return lines
  }
  const chars = [...bottom]
  const cap = [...caption.text]
  const at = Math.max(1, W - 2 - cap.length)
  lines.push({
    press: caption.press,
    segs: [
      { text: chars.slice(0, at).join(''), color: BORDER },
      { text: caption.text, dim: true },
      { text: chars.slice(at + cap.length).join(''), color: BORDER },
    ],
  })
  return lines
}

import type { Task, TaskStatus } from '../types'

// Ported from comet's hooks/lib.ts, with task timers added.
export type TaskCall = {
  readonly tool: string
  readonly agentId?: string
  readonly taskId?: string
  readonly status?: string
  readonly subject?: string
}

type CreateResult = { readonly task: { readonly id: string; readonly subject: string } }
type UpdateResult = { readonly success?: boolean }
type TodoResult = { readonly newTodos: readonly { readonly content: string; readonly status: TaskStatus }[] }

const STATUSES: readonly string[] = ['pending', 'in_progress', 'completed']
const isStatus = (s: string | undefined): s is TaskStatus => s !== undefined && STATUSES.includes(s)

const stamp = (t: Task, status: TaskStatus, now: number): Task => ({
  ...t,
  status,
  ...(status === 'in_progress' && t.startedAt === undefined ? { startedAt: now } : {}),
  ...(status === 'completed' ? { endedAt: now } : {}),
})

export const allDone = (tasks: readonly Task[]) => tasks.length > 0 && tasks.every(t => t.status === 'completed')

export const active = (tasks: readonly Task[]) =>
  tasks.find(t => t.status === 'in_progress') ?? tasks.find(t => t.status === 'pending')

export const applyToolCall = (tasks: readonly Task[], call: TaskCall, result: unknown, now: number): readonly Task[] => {
  if (call.agentId) return tasks
  switch (call.tool) {
    case 'TaskCreate': {
      const { task } = result as CreateResult
      return [...(allDone(tasks) ? [] : tasks), { id: task.id, subject: task.subject, status: 'pending' }]
    }
    case 'TaskUpdate': {
      if ((result as UpdateResult).success === false) return tasks
      if (call.status === 'deleted') return tasks.filter(t => t.id !== call.taskId)
      const status = call.status
      return tasks.map(t => {
        if (t.id !== call.taskId) return t
        const named = call.subject !== undefined ? { ...t, subject: call.subject } : t
        return isStatus(status) ? stamp(named, status, now) : named
      })
    }
    case 'TodoWrite':
      return (result as TodoResult).newTodos.map((t, i) => stamp({ id: String(i), subject: t.content, status: 'pending' }, t.status, now))
    default:
      return tasks
  }
}
```

import type { AgentRow } from '../types'

export const MAX_ROWS = 5

export const spawn = (rows: readonly AgentRow[], row: AgentRow) => [...rows.filter(r => r.id !== row.id), row]

export const stop = (rows: readonly AgentRow[], id: string, now: number) =>
  rows.map(r => (r.id === id && r.endedAt === undefined ? { ...r, endedAt: now } : r))

export const setTokens = (rows: readonly AgentRow[], id: string, n: number) =>
  rows.map(r => (r.id === id ? { ...r, tokens: n } : r))

type UsageLine = { type?: string; message?: { id?: string; usage?: Record<string, number | undefined> } }

// Streaming rewrites a message id with growing usage, so the last line per id wins (as YAS reads it).
export const agentTokens = (jsonl: string) => {
  const byId = new Map<string, number>()
  for (const raw of jsonl.split('\n')) {
    if (!raw.includes('"usage"')) continue
    try {
      const l = JSON.parse(raw) as UsageLine
      const u = l.message?.usage
      if (l.type !== 'assistant' || !u || !l.message?.id) continue
      byId.set(l.message.id, (u.input_tokens ?? 0) + (u.cache_creation_input_tokens ?? 0) + (u.cache_read_input_tokens ?? 0) + (u.output_tokens ?? 0))
    } catch {
      // a line mid-write: the next read has it whole
    }
  }
  return [...byId.values()].reduce((a, b) => a + b, 0)
}

export const onPrompt = (rows: readonly AgentRow[]) => rows.filter(r => r.endedAt === undefined)

export const visible = (rows: readonly AgentRow[]) => {
  const running = rows.filter(r => r.endedAt === undefined)
  const done = rows.filter(r => r.endedAt !== undefined)
  const shown = [...running, ...done].slice(0, MAX_ROWS)
  return {
    shown,
    moreRunning: Math.max(0, running.length - MAX_ROWS),
    doneHidden: done.length - shown.filter(r => r.endedAt !== undefined).length,
  }
}

export const ICON = {
  dir: '\u{F07B}',
  session: '\u{F0369}',
  branch: '\u{E0A0}',
  model: '\u{F06A9}',
  h5: '\u{F13AB}',
  d7: '\u{F00ED}',
  tokens: '\u{F01BC}',
  cache: '\u{F051B}',
  agents: '\u{F070E}',
  workflow: '\u{F0E43}',
  tasks: '\u{F012C}',
  skills: '\u{F0AD}',
}
const SPIN = ['⠋', '⠙', '⠹', '⠸', '⠼', '⠴', '⠦', '⠧', '⠇', '⠏']

export type FixedData = {
  now: number
  cwd: string
  home: string
  sessionName: string | null
  git: Git | null
  model: string
  effort: string | null
  usage: Usage | null
  sessionTokens: number
  cacheLeftMs: number | null
}

// md icons draw wider than one cell; the powerline branch glyph does not
const ic = (icon: string, h: number): Part => ({ text: icon === ICON.branch ? `${icon} ` : `${icon}  `, color: pastel(h) })
const cell = (...parts: Part[]): Cell => ({ parts })
const blank = cell({ text: '' })

const limit = (label: string, l: Limit, icon: string, h: number, now: number) =>
  cell(
    ic(icon, h),
    { text: `${label} ` },
    { text: `${Math.round(l.percent)}%`, color: pastel(h) },
    ...(l.resetsAt === undefined ? [] : [{ text: ` ${fmtDuration(l.resetsAt - now)}`, dim: true }]),
  )

export function fixedRows(d: FixedData, drops: ReadonlySet<Drop>): Section[] {
  const row1: Cell[] = [cell(ic(ICON.dir, 280), { text: drops.has('dirBase') ? basename(d.cwd) : shortenHome(d.cwd, d.home) })]
  const named = !drops.has('sessionName')
  if (named) row1.push(cell(ic(ICON.session, 20), { text: d.sessionName ?? '…', color: pastel(20) }))
  if (d.git) {
    const dirty = d.git.dirty > 0 && !drops.has('dirty') ? [{ text: ` •${d.git.dirty}`, color: pastel(55) }] : []
    row1.push(cell(ic(ICON.branch, 140), { text: d.git.branch }, ...dirty))
  }

  if (d.usage?.fiveHour) row1.push(limit('5h', d.usage.fiveHour, ICON.h5, 200, d.now))
  if (d.usage?.sevenDay && !drops.has('sevenDay')) row1.push(limit('7d', d.usage.sevenDay, ICON.d7, 250, d.now))

  const tokens = d.usage?.contextTokens ?? 0
  const f = fill(tokens, d.usage?.window ?? 0)
  const st = dumbState(f)
  const meter = cell(
    { text: `${st.icon}  `, color: pastel(st.hue) },
    { text: '\u{1FB0B}', grow: f, hues: [160, st.hue] },

    { text: r.model.padEnd(modelW), dim: true },

    { text: ' ', grow: 1 },
    { text: (r.tokens === undefined ? '' : fmtTokens(r.tokens)).padStart(5), dim: true },
    { text: fmtDuration((r.endedAt ?? now) - r.startedAt).padStart(6), dim: true },
    { text: '  ' },
    done ? { text: '✓', color: pastel(150) } : { text: SPIN[(f + i * 3) % SPIN.length] ?? '⠋', color: pastel(h) },
  )
}

const group = (label: Cell, rows: readonly AgentRow[], tail: string | null, now: number, f: number): Section => {
  const nameW = Math.max(...rows.map(r => width(r.name))) + 2
  const modelW = Math.max(...rows.map(r => width(r.model))) + 2
  const body: Cell[][] = rows.map((r, i) => [i === 0 ? label : blank, agentBody(r, i, nameW, modelW, now, f)])
  if (tail) body.push([blank, cell({ text: tail, dim: true })])
  return { rows: body, flex: 1 }
}

export function agentSections(rows: readonly AgentRow[], runs: Readonly<Record<string, string>>, now: number, f: number): Section[] {
  const v = visible(rows)
  if (v.shown.length === 0) return []
  const tail = [v.moreRunning > 0 ? `+${v.moreRunning} more` : '', v.doneHidden > 0 ? `✓ ${v.doneHidden} done` : '']
    .filter(Boolean)
    .join('  ')
  const plain = v.shown.filter(r => r.runId === undefined)
  const sections: Section[] = []
  if (plain.length > 0) {
    const running = plain.filter(r => r.endedAt === undefined).length
    sections.push(group(cell(ic(ICON.agents, 330), { text: 'agents ' }, { text: String(running), bold: true }), plain, null, now, f))
  }
  for (const runId of [...new Set(v.shown.flatMap(r => (r.runId === undefined ? [] : [r.runId])))]) {
    const members = v.shown.filter(r => r.runId === runId)
    sections.push(group(cell(ic(ICON.workflow, 270), { text: runs[runId] ?? 'workflow' }), members, null, now, f))
  }
  const last = sections.pop()
  if (last) sections.push(tail ? { ...last, rows: [...last.rows, [blank, cell({ text: tail, dim: true })]] } : last)
  return sections
}

const taskLine = (t: Task, now: number, f: number): Cell => {
  const timer = t.startedAt === undefined ? '' : fmtDuration((t.endedAt ?? now) - t.startedAt)
  if (t.status === 'completed') return cell({ text: '✓ ', color: pastel(150) }, { text: t.subject, dim: true }, { text: ' ', grow: 1 }, { text: timer.padStart(6), dim: true })
  if (t.status === 'in_progress') return cell({ text: '▸ ', color: pastel((f * 6) % 360) }, { text: t.subject }, { text: ' ', grow: 1 }, { text: timer.padStart(6), dim: true })
  return cell({ text: '○ ', dim: true }, { text: t.subject, dim: true }, { text: ' ', grow: 1 }, { text: ''.padStart(6) })
}

export function taskSection(tasks: readonly Task[], open: boolean, now: number, f: number): Section | null {
  if (tasks.length === 0) return null
  const done = tasks.filter(t => t.status === 'completed').length
  const label = cell(ic(ICON.tasks, 150), { text: 'tasks ' }, { text: `${done}/${tasks.length}`, bold: true }, { text: open ? ' ▾' : ' ▸', dim: true })
  const current = active(tasks)
  const rows: Cell[][] = open
    ? tasks.map((t, i) => [i === 0 ? label : blank, taskLine(t, now, f)])
    : [[label, current ? taskLine(current, now, f) : cell({ text: 'all done', dim: true })]]
  return { rows, flex: 1, press: 'tasks' }
}

export function skillsSection(skills: readonly string[], plugins: readonly string[]): Section {
  return {
    rows: [[
      cell(ic(ICON.skills, 60), { text: 'skills ' }, { text: String(skills.length), bold: true }),
      cell({ text: skills.join(' · ') || 'none yet', dim: true }),
      cell(ic(ICON.skills, 20), { text: 'plugins ' }, { text: plugins.join(' · '), dim: true }),
    ]],
    flex: 1,
  }
}

// Claude Code's session registry (~/.claude/sessions/<pid>.json) holds the Session Name beside the session id.
export function sessionNameFrom(files: readonly { name: string; text: string }[], sessionId: string): string | null {
  for (const f of files) {
    try {
      const s = JSON.parse(f.text) as { sessionId?: unknown; name?: unknown }
      if (s.sessionId === sessionId && typeof s.name === 'string') return s.name
    } catch {
      // a registry file mid-write: skip it; the next turn reads it again
    }
  }
  return null
}

import { atom, read, update } from 'claude-code'
import type { EngineInterface, Register, Timer } from 'claude-code'

import type { AgentRow, Limit, Task, Usage } from '../types'
import { agentTokens, onPrompt, setTokens, spawn, stop } from './agents'
import { cacheLeft, parseGit } from './format'
import { draw, planDrops, rowWidth } from './frame'
import type { Drop, Line } from './frame'
import { agentSections, fixedRows, ICON, sessionNameFrom, skillsSection, taskSection } from './rows'
import type { FixedData } from './rows'
import { applyToolCall } from './tasks'
import type { TaskCall } from './tasks'

const P = 'cockpit'
const frame = atom({ plugin: P, key: 'frame' } as const, 0)
const home = atom({ plugin: P, key: 'home' } as const, '')
const configDir = atom({ plugin: P, key: 'configDir' } as const, '')
const cwd = atom({ plugin: P, key: 'cwd' } as const, '')
const usage = atom({ plugin: P, key: 'usage' } as const, null as Usage | null)
const model = atom({ plugin: P, key: 'model' } as const, '')
const effort = atom({ plugin: P, key: 'effort' } as const, null as string | null)
const git = atom({ plugin: P, key: 'git' } as const, null as { branch: string; dirty: number } | null)
const sessionName = atom({ plugin: P, key: 'sessionName' } as const, null as string | null)
const sessionTokens = atom({ plugin: P, key: 'sessionTokens' } as const, 0)
const lastResponseAt = atom({ plugin: P, key: 'lastResponseAt' } as const, null as number | null)
const tasks = atom({ plugin: P, key: 'tasks' } as const, [] as readonly Task[])
const tasksOpen = atom({ plugin: P, key: 'tasksOpen' } as const, false)
const agents = atom({ plugin: P, key: 'agents' } as const, [] as readonly AgentRow[])
const agentDir = atom({ plugin: P, key: 'agentDir' } as const, '')
const runs = atom({ plugin: P, key: 'runs' } as const, {} as Readonly<Record<string, string>>)
const skills = atom({ plugin: P, key: 'skills' } as const, [] as readonly string[])
const plugins = atom({ plugin: P, key: 'plugins' } as const, [] as readonly string[])
const showSkills = atom({ plugin: P, key: 'showSkills' } as const, false)

type Measure = { context: { tokens?: number; window: number }; rateLimits: readonly { kind: string; percentUsed: number; resetsAt?: string }[] }

const toLimit = (l: Measure['rateLimits'][number] | undefined): Limit | undefined =>
  l === undefined ? undefined : { percent: l.percentUsed, ...(l.resetsAt ? { resetsAt: Date.parse(l.resetsAt) } : {}) }

const toUsage = (m: Measure): Usage => ({
  contextTokens: m.context.tokens ?? 0,
  window: m.context.window,
  fiveHour: toLimit(m.rateLimits.find(l => l.kind === 'five_hour')),
  sevenDay: toLimit(m.rateLimits.find(l => l.kind === 'seven_day')),
})

async function refreshGit($: EngineInterface) {
  const dir = await read($, cwd)
  if (!dir) return
  try {
    const r = await $.process.run(['git', 'status', '--porcelain=v1', '--branch'], { cwd: dir, timeoutMs: 2000 })
    await update($, git, () => parseGit(r.exitCode, r.stdout))
  } catch {
    await update($, git, () => null)
  }
}

async function refreshSessionName($: EngineInterface) {
  try {
    const dir = `${await read($, configDir)}/sessions`
    const id = await $.session.id()
    const names = (await $.fs.list(dir)).filter(f => f.name.endsWith('.json'))
    const files = await Promise.all(names.map(async f => ({ name: f.name, text: await $.fs.read(`${dir}/${f.name}`).catch(() => '') })))
    const name = sessionNameFrom(files, id)
    if (name) await update($, sessionName, () => name)
  } catch {
    // the registry is Claude Code's internal state; without it the cell shows …
  }
}

// Live subagent tokens: re-read each running agent's transcript (a read over 4 MiB rejects; keep the last count).
async function refreshAgentTokens($: EngineInterface) {
  const dir = await read($, agentDir)
  if (!dir) return
  for (const r of await read($, agents)) {
    if (r.endedAt !== undefined && r.tokens !== undefined) continue
    try {
      // workflow agents sit one level deeper: subagents/workflows/<runId>/agent-<id>.jsonl (from YAS; unverified here)
      const file = r.runId === undefined ? `${dir}/agent-${r.id}.jsonl` : `${dir}/workflows/${r.runId}/agent-${r.id}.jsonl`
      const n = agentTokens(await $.fs.read(file))
      await update($, agents, rows => setTokens(rows, r.id, n))
    } catch {
      // not written yet, or too large to read
    }
  }
}

async function refreshSession($: EngineInterface) {
  const env = await $.process.run(['sh', '-c', 'printf "%s\\n%s" "$HOME" "${CLAUDE_CONFIG_DIR:-$HOME/.claude}"'])
  const [h = '', c = ''] = env.stdout.split('\n')
  await update($, home, () => h)
  await update($, configDir, () => c)
  const dir = await $.session.cwd()
  await update($, cwd, () => dir)
  const m = await $.session.model()
  await update($, model, () => m)
  const u = await $.session.usage()
  await update($, usage, () => toUsage(u))
  const settings = await $.settings.read()
  const enabled = (settings.enabledPlugins ?? {}) as Record<string, unknown>
  await update($, plugins, () => Object.keys(enabled).filter(k => enabled[k] === true).map(k => k.split('@')[0] ?? k))
  await refreshGit($)
  await refreshSessionName($)
}

export const register: Register = on => {
  let tick: Timer | undefined
  let poll: Timer | undefined

  on('session.start', async ($, e, next) => {
    await $.command.register({ name: 'cockpit-skills', description: 'Toggle the skills/plugins row in the cockpit panel' })
    tick ??= $.clock.every(120, () => update($, frame, n => n + 1))
    poll ??= $.clock.every(2000, () => refreshAgentTokens($))
    try {
      await refreshSession($)
    } catch {
      // each cell shows … until its own event fills it
    }
    return next(e)
  })

  on('command.run', { command: 'cockpit-skills' }, async $ => {
    await update($, showSkills, v => !v)
    return { text: 'Toggled the cockpit skills/plugins row.' }
  })

  on('session.measure', async ($, e, next) => {
    await update($, usage, () => toUsage(e))
    return next(e)
  })

  // Agent Rows live until the next user prompt
  on('prompt.submit', async ($, e, next) => {
    await update($, agents, rows => onPrompt(rows))
    await refreshSessionName($)
    return next(e)
  })

  // turn.step is a streaming event; effort rides on classic hook inputs instead
  on('classic.PostToolUse', async ($, e, next) => {
    const level = e.effort?.level
    if (level) await update($, effort, () => level)
    return next(e)
  })

  on('classic.PostModelSwitch', async ($, e, next) => {
    await update($, model, () => e.to_model)
    return next(e)
  })

  on('turn.complete', async ($, e, next) => {
    const u = e.usage
    const n = u ? u.input_tokens + u.output_tokens + u.cache_read_input_tokens + u.cache_creation_input_tokens : 0
    await update($, sessionTokens, t => t + n)
    if (!e.agentId) {
      const now = await $.clock.now()
      await update($, lastResponseAt, () => now)
      await refreshGit($)
    }
    return next(e)
  })

  on('classic.CwdChanged', async ($, e, next) => {
    await update($, cwd, () => e.new_cwd)
    await refreshGit($)
    return next(e)
  })

  on('agent.spawn', async ($, e, next) => {
    const r = await next(e)
    if (r.deny !== undefined) return r
    // the engine's own unnamed forks (compaction, memory) are not the user's agents
    if (e.fork && !e.name) return r
    const now = await $.clock.now()
    const row: AgentRow = {
      id: r.agentId ?? e.tool_use_id,
      name: e.name ?? e.subagentType,
      model: r.model,
      description: e.description,
      startedAt: now,
      ...(e.workflow ? { runId: e.workflow.runId } : {}),
    }
    await update($, agents, rows => spawn(rows, row))
    return r
  })

  on('classic.SubagentStop', async ($, e, next) => {
    const now = await $.clock.now()
    await update($, agents, rows => stop(rows, e.agent_id, now))
    await refreshAgentTokens($)
    return next(e)
  })

  on('tool.call', { tool: ['TaskCreate', 'TaskUpdate', 'TodoWrite'] }, async ($, e, next) => {
    const r = await next(e)
    if ('result' in r && r.result !== undefined && !r.isError) {
      const now = await $.clock.now()
      await update($, tasks, list => applyToolCall(list, e as unknown as TaskCall, r.result, now))
    }
    return r
  })

  on('tool.call', { tool: 'Workflow' }, async ($, e, next) => {
    const r = await next(e)
    if ('result' in r && r.result !== undefined && !r.isError) {
      const w = r.result as { runId?: string; workflowName?: string }
      if (w.runId && w.workflowName) {
        const id = w.runId
        const name = w.workflowName
        await update($, runs, m => ({ ...m, [id]: name }))
      }
    }
    return r
  })

  on('tool.call', { tool: 'Skill' }, async ($, e, next) => {
    const r = await next(e)
    const name = String((e as unknown as { skill?: unknown }).skill ?? '')
    if (name) await update($, skills, list => (list.includes(name) ? list : [...list, name]))
    return r
  })

  // session.start never fires on /clear or an in-process resume; the classic event does
  on('classic.SessionStart', async ($, e, next) => {
    const r = await next(e)
    const dir = `${e.transcript_path.replace(/\.jsonl$/, '')}/subagents`
    await update($, agentDir, () => dir)
    try {
      const res = await $.tool.call({ tool: 'TaskList' })
      if ('result' in res && res.result !== undefined && !res.isError) {
        const seeded = res.result.tasks.map(t => ({ id: t.id, subject: t.subject, status: t.status }))
        await update($, tasks, () => seeded)
      }
    } catch {
      // keep the current list until the next task call
    }
    if (e.source === 'clear') {
      await update($, sessionTokens, () => 0)
      await update($, agents, () => [])
    }
    return r
  })

  on('ui.render', { component: 'AbovePrompt' }, async ($, e, next) => {
    // other plugins share the band: draw beneath ours, never replace it
    const below = await next(e)
    if (e.props.hasSurvey) return below
    const { Box, Text, Button } = $.ui.resolve(e)
    const f = await read($, frame)
    const now = await $.clock.now()
    const W = Math.max(40, e.props.bodyColumns)

    const data: FixedData = {
      now,
      cwd: await read($, cwd),
      home: await read($, home),
      sessionName: await read($, sessionName),
      git: await read($, git),
      model: await read($, model),
      effort: await read($, effort),
      usage: await read($, usage),
      sessionTokens: await read($, sessionTokens),
      cacheLeftMs: cacheLeft(await read($, lastResponseAt), now),
    }
    const need = (drops: ReadonlySet<Drop>) => Math.max(...fixedRows(data, drops).map(s => rowWidth(s.rows[0] ?? [])))
    const drops = planDrops(need, W)

    const list = await read($, tasks)
    const tasksSec = taskSection(list, await read($, tasksOpen), now, f)
    const skillList = await read($, skills)
    const sections = [
      ...fixedRows(data, drops),
      ...agentSections(await read($, agents), await read($, runs), now, f),
      ...(tasksSec ? [tasksSec] : []),
      ...((await read($, showSkills)) ? [skillsSection(skillList, await read($, plugins))] : []),
    ]
    const caption = { text: ` ${ICON.skills}  ${skillList.length} skills ${(await read($, showSkills)) ? '▾' : '▸'} `, press: 'skills' }
    const press: Record<string, () => void> = {
      tasks: () => void update($, tasksOpen, v => !v),
      skills: () => void update($, showSkills, v => !v),
    }

    const panel = draw(sections, W, f, caption).map((l, i) => {
      const row = (
        <Text wrap="truncate-end">
          {l.segs.map(s => (
            <Text color={s.color} dimColor={s.dim} bold={s.bold}>
              {s.text}
            </Text>
          ))}
        </Text>
      )
      const onPress = l.press ? press[l.press] : undefined
      return onPress ? (
        <Button key={`${l.press}-${i}`} plain onPress={onPress}>
          {row}
        </Button>
      ) : (
        row
      )
    })

    return (
      <Box flexDirection="column">
        {below}
        {panel}
      </Box>
    )
  })
}
